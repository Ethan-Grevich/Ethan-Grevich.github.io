# Project 1: Recursion Visualizer

The Recursion Visualizer is a Java desktop application that makes recursive functions easier to follow. Choose an example and step through its calls and returns while the call tree and stack update.

## Examples

- Factorial
- Fibonacci
- Sum from 1 to n
- Binary search

Use **Start** to build an example, **Back** and **Next** to move through its steps, or **Play** to watch the trace.

## Run it

This is a Java Swing desktop application, so it runs on a computer with a JDK installed rather than inside this webpage.

1. [Download the Java source]({{ '/Project.java' | relative_url }}).
2. Open a terminal in the folder where you saved `Project.java`.
3. Compile and launch it:

   ```text
   javac Project.java
   java Project
   ```
